# Public-record hygiene

This repository is public, and everything committed to it — acceptance transcripts, montages, screenshots,
captions — is read by people who have only a clone. This skill is the rule, the guard, and the procedure for
when the rule has already been broken.

## When to Use

- You are about to commit anything generated by a run (transcript, caption, screenshot, record).
- You are writing a doc that quotes an endpoint, a hostname or a path from the machine the work was done on.
- A guard or a reviewer reports an identity-shaped value in the tree.

## The rule

**A public artifact carries labels, never live endpoints** (`docs/ux-v2/DECISIONS.md` §11):

| Value | What to write |
|---|---|
| loopback (`127.0.0.1:3005`) | **verbatim** — it identifies nobody, and it is a useful diagnostic |
| an identity-shaped host | `http://<box>.<tailnet>.ts.net` — scheme, port and path kept |
| a literal address, a private DNS suffix (`.ts.net`, `.local`, `.internal`, `.lan`), `os.hostname()` | redacted |
| a public host (the GitHub remote, upstream docs) | untouched |

`.home` is deliberately **not** a private suffix — it collides with ordinary identifiers such as
`process.env.HOME` and `landing.home`, and a rule that flags them is a rule that gets switched off.

**Credentials are referenced by key name only.** No secret, token or password in a file, a transcript or a commit
message; the live values belong to the instance env files, which live outside this repo. An env file's *values*
are never printed to a transcript, not even to debug.

## Procedure — a leak found in committed text

1. **Fix the emitter first.** Both emitters route through `harness/redact.mjs` (`read-pass.sh` calls
   `harness/redact-url.mjs`; `verify-page.mjs` imports it; the focus pass has its own redacted header). Fixing the
   committed files alone guarantees the next pass re-creates the leak.
2. **Redact the committed records in place**, as a **presentation-only** change: no measured value is altered, so
   no acceptance re-run is required for it.
3. **Run the guard**: `bun run harness:records`. It asserts the rule's unit cases *and* scans the public tree for
   identity-shaped text; only the rule and its own suite are excluded. Completion: 0 offences, and the scan count
   is reported.
4. **Prove it on a fresh clone** (the reviewer's path, not yours): clone the public remote, grep the header and
   the tree for the address, the suffix and the hostname. A shallow single-branch clone has no `origin/main`, so
   fetch it (`git fetch --depth 1 origin main:refs/remotes/origin/main`) before claiming the diff check ran.
5. **Prove the generator too**: run one pass against an instance whose dashboard *is* an identity-shaped URL and
   confirm the transcript's header carries the label and the tree holds no live endpoint.
6. **Say what remains.** If the value is in published *history*, report it with its commit count and let a human
   decide; the standing rule is **do not rewrite** — a rewrite cannot guarantee erasure from clones, caches and
   forks, and it invalidates every hash for no gain while the tree and `main` are clean.

## Pitfalls

1. **"It is governed elsewhere" is not an exemption.** A live endpoint in a public repo is a leak even when the
   estate keeps the same value for real use.
2. **The guard's false positives are informative.** HTML-escaped placeholders (`&lt;box&gt;`), public URLs, and
   `.home` in `process.env.HOME` all appeared; narrowing the predicate while asserting the two narrowing decisions
   in the rule's own test suite is what stops them silently regressing back.
3. **A guard that scans only `docs/` is half a guard.** Scan the whole public tree.
4. **A proof run can republish committed screenshots** as a side effect (the pass owns them). Revert them and
   amend so a redaction commit stays text-only — then say so in the record.
5. **Doc hygiene covers prose, not just records.** No personal identifiers anywhere — accounts, local usernames,
   device hostnames, tailnet names, private-repo URLs. Public upstream references stay.
6. **Do not point-fix addresses by hand** where a standing agenda item governs how endpoints are recorded; fix the
   rule and the emitter.

## Verification

- `bun run harness:records` green, with the scanned-file count reported.
- A fresh clone of the public remote: header carries the label, tree grep clean for every identifier class.
- The rule's own suite includes the negative cases (the narrowing decisions), so a future loosening fails a test.
