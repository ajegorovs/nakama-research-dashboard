# Legacy fidelity tooling

These scripts produced the earlier UX-v2 comparison packs. They retain five-tab and retired
Overview assumptions and are **not verified for the current four-view dashboard**.
Do not use historical montages as the current visual specification or claim a current fidelity
pass from these helpers. The current specification is
[the four-view architecture](../../docs/design/dashboard-information-architecture-pivot.md).

For current UI iteration use [the standalone preview](../preview/README.md) and a real browser.
Adapting these capture/montage scripts requires a separately scoped tool change and verification.
Frozen HTML reference inputs and recorded non-Markdown captures remain untouched by Markdown
retirement. Earlier operator instructions are recoverable from the baseline in
[the documentation map](../../docs/README.md).
